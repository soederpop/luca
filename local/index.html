How it is built.

One containerThe same container that runs Luca on the server runs in the browser. Features, state, and an event bus.
One loadertransformers loads transformers.js, picks WebGPU or WASM, and turns download progress into state.
One part per taskembeddings, localLlm, transcriber, vision. Each owns one model and a small state schema.
The page reads statePages watch feature.state.observe() and feature.on('*'). No framework needed. React works too.

Every demo is a few lines against the container. This is the chat page, without the markup:

// the web container: the same API as on the server
const llm = container.feature('localLlm', { model: 'HuggingFaceTB/SmolLM2-360M-Instruct' })
llm.on('token', (piece) => output.textContent += piece)
await llm.chat('What is a container?')
llm.state.get('tokensPerSecond')   // decoding speed on your GPU

Models download once from the Hugging Face hub and stay in your browser's cache. After that, every page here works offline. WebGPU works in Chrome and Edge 113+ and Safari 26+. Everything else falls back to WASM.

Put it in any page.

No install and no build step. One script tag loads the whole web container from esm.sh, and it is also on window.luca.

<script type="module">
  import container from 'https://esm.sh/luca/web'

  const llm = container.feature('localLlm')
  llm.on('token', (piece) => document.body.append(piece))
  await llm.chat('Say hello in five words.')
</script>

Pin a version when you need it to stay the same: https://esm.sh/luca@3.27.5/web. Using a bundler? bun add luca, then import container from 'luca/web'. Run luca describe localLlm for the full API.
