Part COptional · macOS

The workbench.

You only need the CLI. Luca Desktop is a visual workbench on top of it: every project, component, and agent on your Mac, in one keyboard-first window.

luca desktop install --open

macOS 15.4 or later. Needs the luca CLI, version 3.27 or later. Signed and notarized by Apple. Free and open source.

1
Space P projects

Your whole portfolio on one shelf.

Every Luca project on your Mac gets its own workspace. Switch between them with a key.

Ask the lucaPortfolio assistant about all of them at once: which project already talks to Postgres, or which one has the component you need.

It can carry a component from one project into another. You review each change before anything is written. That is how your collection grows.

2
Space r registry

See everything in the project.

Your own components and the built-in ones sit side by side, each marked by where it came from.

Open one to read its methods, options, and docs. When it is running, its live state and events update as they happen. The docs are the same ones luca describe prints.

3
Space n chat

Talk to the agents inside.

Every agent in your project is one key away. Replies stream in, with each tool call as it happens.

Run on an API key, a local model, or your Claude Code or Codex subscription. Conversations are saved per project. It ships with lucaArchitect, an agent that builds with Luca.

4
Space e console · Space h endpoints

Try some code. Hit an endpoint.

5
Space d docs · Space Space palette

Your docs. Every key.

How it works

The app draws. Your project does the work.

01

Point Luca Desktop at any Luca project folder. It gives the folder a workspace.

02

The app runs luca workbench in that folder: a token-guarded API on 127.0.0.1, over the project's own container.

03

Every tile reads and writes through that host. It listens only on your Mac. Close the last tile and it stops.

Get the CLI. Then the bench.

Install the luca CLI, then let it install the app.

curl -fsSL https://luca-js.soederpop.com/install.sh | bash
luca desktop install --open
