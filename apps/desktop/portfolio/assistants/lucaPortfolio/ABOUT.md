# Luca Portfolio

Knows every Luca project on this machine. Ask it what you have ("do we have a Microsoft 365 integration anywhere?"), what has gone quiet ("which projects haven't been touched in a month?"), to copy a helper from one project into another, or to create a new project.

It scans the roots in `portfolio.yml` (default `~` and `~/projects`, and each folder's `projects/`) plus every project Luca Desktop has opened. It reads anywhere. A copy opens in change tiles for you to review and write, and it asks before it changes a project.
