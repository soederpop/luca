# the commands you will use most
bootstrap   start a new project
chat        talk to your project's agents
describe    read the docs for any component
eval        try code live, everything in scope
prompt      hand a task to Claude Code, Codex, Hermes
scaffold    make a new component or agent
serve       turn endpoints/ into an API
bundle      ship the project as its own binary
1
Open the box

Start a project.

One command lays out a project the way every Luca project is laid out.

Folders for commands, API endpoints, your own components, your agents, and your docs. Your coding agent gets a guide to the whole kit, so it knows the rules before it writes a line.

luca bootstrap my-app
cd my-app

# what you get
commands/     luca <name> runs these
endpoints/    file-based API routes
features/     your own components
assistants/   your own agents
docs/         markdown your app can query
2
The builder

Talk to it.

Say what you want. The agent finds the right parts, reads their instructions, and snaps them together.

It checks its own work by running code against the real components, not by guessing. When it is unsure how a part works, it asks the part.

# chat with your project's agent
luca chat

# the agent's reference, and yours
luca describe features
luca describe scheduler
luca describe scheduler.cron

# try an idea before you commit to it
luca eval "container.feature('os').platform"
3
The foreman

Command your other agents.

Already pay for Claude Code or Codex? Luca puts them to work.

Write a task as a markdown file. Send it to one agent, or send a folder of tasks to several at once and watch them side by side. Save every session to a file so you can read what happened.

# one task, one agent
luca prompt claude tasks/add-billing.md

# a stack of tasks, run in parallel
luca prompt codex tasks/*.md --parallel

# keep a record
luca prompt hermes tasks/audit.md --out-file logs/audit.md
4
Your own agents

Make a single-purpose agent.

An agent is a folder with a markdown file. Scaffold one, then write who it is.

Give it tools in tools.ts when it needs to touch something. Give it hooks when it needs to react. Wake it with a schedule, an email, a text, or a socket message.

luca scaffold assistant front-desk

assistants/front-desk/
  CORE.md     who it is, what it does
  tools.ts    what it can touch
  hooks.ts    what it reacts to

luca chat front-desk
5
Run it

Serve it.

Every file in endpoints/ becomes a route. One command serves them, with your static site beside them.

Add a WebSocket server, an MCP server, or an IPC socket from the same box when other programs or other agents need a way in.

luca serve --port 3000

# expose this project to other AI agents
luca mcp
6
Ship it

One binary in. One binary out.

luca bundle compiles your commands, endpoints, components, and agents into one file.

Build for macOS and Linux. The people who run it do not install Luca, Bun, or node_modules. They bring their own model provider and keys.

luca bundle my-app --targets darwin-arm64,linux-x64

./dist/my-app-darwin-arm64 <your command>

Install the kit.
