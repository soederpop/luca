# Notes

Working notes for people building Luca: ideas, plans, reports, and agent prompts.
Nothing here ships. Product docs live in `docs/` (tutorials, examples, bootstrap,
scaffolds, APIs).

- `ideas/` design ideas and theory, not committed to
- `plans/` implementation plans
- `reports/` evaluations and audits (`luca doctest-jsdoc` writes here)
- `prompts/` reusable prompts for agent-run audits
- `sessions/` challenge attempt logs from `luca try-challenge` (git-ignored)
