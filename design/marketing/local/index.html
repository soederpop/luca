Six demos built on the Luca web container. Each one is a feature: it loads a model through transformers.js, runs it on your GPU with WebGPU (or WASM), and reports what it is doing through container state and events. The inspector on every page shows that happening live.

How it is built

One containerThe same container object that runs luca on the server runs in the browser. Features, state, and an event bus.
One loadertransformers imports transformers.js from a CDN, picks WebGPU or WASM, and turns per-file download callbacks into state.
One feature per taskembeddings, localLlm, transcriber, vision. Each owns a pipeline and a small state schema.
UI reads statePages subscribe to feature.state.observe() and feature.on('*'). No framework required; React works too.

Every demo is a few lines against the container. This is the chat page, minus the markup:

// luca is the web container, same API as on the server
const llm = container.feature('localLlm', { model: 'HuggingFaceTB/SmolLM2-360M-Instruct' })
llm.on('token', (piece) => output.textContent += piece)
await llm.chat('What is a container?')
llm.state.get('tokensPerSecond')   // decoding speed on your GPU

Models come from the Hugging Face hub and are stored in the browser's Cache API, so the download happens once. After that, every page here works offline. Browser support: WebGPU in Chrome and Edge 113+, Safari 26+. Everything falls back to WASM.

Use it yourself: bun add luca, then import container from 'luca/web'. Run luca describe localLlm for the full API of any feature.
