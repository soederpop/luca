More building.

Start with one container. Add the capabilities you need. Let humans and agents build on the same foundation.

app.ts
import container from 'luca'

// Your application's toolkit, in one place.
const fs = container.feature('fs')
const api = container.client('rest', {
  baseURL: 'https://api.example.com',
})
const server = container.server('express')

// Ask the runtime what else is available.
container.features.available
